# Finance 7x24 News IntelliJ Plugin

Finance 7x24 News 是一个 IntelliJ IDEA 工具窗口插件，用于在 IDE 内查看 7x24 财经快讯，并维护股票、ETF、指数的自选行情。

## 功能

- 在 IDEA 右侧工具窗口展示 7x24 财经快讯
- 快讯卡片右上角「AI 解读」：一句话定性利多/利空、关联自选股说明影响、给出后续跟踪点，解读结果在 AI 会话页签中可继续追问
- 快讯支持自动刷新、手动刷新和内容自动换行
- 提供自选行情标签页，支持股票、ETF 和指数代码
- 自选列表名称与代码两行展示
- 自选行情支持添加、右键删除、手动刷新和自动刷新
- 支持按表头排序，连续点击可在倒序、正序、默认顺序间切换
- 行情接口支持多数据源兜底，优先使用东方财富，失败时自动尝试腾讯财经和新浪财经
- 行情涨跌使用 A 股习惯配色：上涨红色，下跌绿色
- 支持 A 股 / 港股 / 美股 / 国际金价（伦敦金 XAU/USD）自选行情
- 自选页提供市场筛选标签：A 股 / 港股 / 美股 / 黄金
- 各市场自动刷新，均按各自开市时段运行，闭市时自动暂停并显示"闭市中"
- 搜索框可搜索 A 股、港股、美股（带市场标签）
- 底部展示大盘指数实时行情，按当前市场筛选标签自动切换（A股/港股/美股/黄金指数）
- **AI 自选股分析**：基于实时行情一键分析自选组合，自动接入日K均线数据（MA5/10/20/60），支持多轮追问对话
- **AI速览**：汇总最近一批快讯要点，按三段中文结构输出，可在 AI 会话页签中继续追问
- **多份 AI 服务配置**：可保存多份独立的接口地址 / 模型 ID / API Key，随时切换；内置常用服务预设模板，也支持任意 OpenAI 兼容接口
- 工具窗口标题栏常驻「AI速览」「AI选股分析」「AI 设置」快捷入口，快讯 / 自选任意页签下都能一键直达
- AI 会话作为工具窗口内的页签打开，不再弹独立窗口：可随工具窗口最小化/隐藏，页签带关闭按钮，会话期间切走再点入口即可恢复

## AI 功能

### 入口

工具窗口标题栏右侧常驻三个图标入口，悬停显示名称，任意页签下都可直接点击：

- **AI速览**：汇总最近一批快讯要点，按三段中文结构输出，可继续追问
- **AI选股分析**：分析当前市场筛选下的自选组合，支持多轮追问
- **AI 设置**：打开设置对话框

### AI 服务配置

设置入口：工具窗口标题栏齿轮，或 **IDE 设置（Settings → Tools → Finance 7x24 News AI）**，两处共用同一份配置。

可保存多份独立配置，每份包含名称、接口地址（BaseURL，自动补全 `/chat/completions`）、模型 ID 与 API Key；配置下拉中选中的一份即为当前使用的服务，支持新建、删除、改名与随时切换。每份 Key 按配置单独加密保存，互不覆盖；删除配置时同步清除对应凭据。

新建配置时可从预设模板一键填充常用服务参数（商汤 SenseNova、智谱 GLM 等），也可选「空白配置」接入任意 OpenAI 兼容端点（中转代理、私有部署、本地推理服务等）。旧版单份自定义配置与内置模型选择会在升级后自动迁移成配置列表。

### 首次使用

1. 点击工具窗口标题栏的齿轮（AI 设置）
2. 点「新建」选一个预设模板，或直接在默认配置上填写接口地址与模型 ID
3. 填入对应服务的 API Key，点「测试连接」确认可用，再点「保存」
4. 点击标题栏的「AI速览」或「AI选股分析」即可发起

之后点击入口会直接基于最新行情生成，无需重复配置；更换 Key、模型或切换服务，随时回到设置页修改。

### 数据与隐私

- API Key 保存在 IDE 的凭据存储中（PasswordSafe，对应 macOS 钥匙串 / Windows 凭据管理器 / Linux KeePass），每份配置独立一条、切换或删除互不影响，不明文落盘
- 旧版本曾将 Key 明文保存在 `~/.finance7x24_ai_config.json`；升级后会自动将该文件中的 Key 迁移到凭据存储，并从原文件剔除，无残留 Key 时删除该文件
- 发送给所选 AI 服务的内容包括：自选代码与实时行情、被解读快讯的标题与摘要、你在 AI 会话中输入的消息（不含 IDE 中的代码、文件或其他项目信息）
- AI 输出基于模型生成，仅供参考，不构成任何投资建议

## 安装

### 从 JetBrains Marketplace 安装

可搜索 `Finance 7x24 News` 安装，或直接访问 JetBrains Marketplace 插件页安装。

### 从本地文件安装

运行以下命令构建插件包：

```bash
./gradlew buildPlugin
```

然后在 IDEA 中选择 `Settings` -> `Plugins` -> 齿轮图标 -> `Install Plugin from Disk...`，选择 `build/distributions/` 下生成的 zip 文件。

## 兼容性

- IntelliJ IDEA 2024.1 及以上版本（sinceBuild 241，不设上限版本）
- 基于 IntelliJ Platform 2024.1.7 构建，Gradle Wrapper 9.6.1

## 开发

环境要求：JDK 17 及以上（IntelliJ Platform 2024.1 的要求）。常用任务：

```bash
./gradlew buildPlugin   # 构建插件包，输出到 build/distributions/
./gradlew runIde        # 启动沙箱 IDEA 实例进行本地调试
```

代码结构（`src/main/java/com/plugin/finance/`）：

```
├── KuaixunToolWindowFactory   # 工具窗口入口，注册标题栏 AI 快捷入口
├── KuaixunPanel               # 快讯页：卡片列表 + 自动刷新 + 页签容器
├── WatchlistPanel             # 自选页：行情表格 / 市场筛选 / 大盘指数 / AI 会话入口
├── AiChatPanel                # AI 会话面板（工具窗口页签内）
├── QuoteService                # 行情多级兜底 + 日K均线计算
├── KuaixunService              # 快讯接口
├── StockSearchDialog/Service   # 股票搜索
├── AIService                   # 预设模板 / 多配置持久化与迁移 / 提示词 / Key 凭据存储 / 接口调用
├── AISettingsPanel             # 设置表单（配置列表 + 编辑 + 测试连接），设置页与对话框共用
├── AISettingsDialog/Configurable  # 设置对话框 / IDE 设置页
├── AiQuickActions / ShowAiSettingsAction  # 工具窗口标题栏快捷入口
└── 其余为模型类与工具类          # QuoteItem / KuaixunItem / MarketType / CodeUtils / GoldInstrument
```

架构设计、线程模型、持久化键与已知限制等实现细节见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 数据来源

插件展示的财经快讯来自公开财经快讯接口。自选行情按以下优先级尝试数据源：

1. **东方财富**（延迟行情 JSON 接口，UTF-8）
2. **腾讯财经**（GBK 编码文本接口）
3. **新浪财经**（GBK 编码文本接口）

任一数据源成功即使用，全部失败时提示网络异常。

自选代码格式：

| 市场 | 格式 | 示例 |
|------|------|------|
| A 股 | `sh`/`sz` + 6 位代码 | `sh600000`、`sz000001` |
| 指数 | `sh` + 6 位代码 | `sh000001` |
| 港股 | `hk` + 5 位代码 | `hk00700` |
| 美股 | `us` + 字母代码 | `usAAPL` |
| 黄金/贵金属 | 内置品种库代码 | `xau`（伦敦金）、`gc`（纽约金）、`xag`（伦敦银）、`si`（纽约白银） |

公开接口的数据内容、更新频率、实时性和可用性均取决于对应数据来源服务，插件不会保证行情数据实时、完整或持续可用。
